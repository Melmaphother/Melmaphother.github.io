# Daoyu Wang - Homepage

My personal academic homepage, featuring research interests, publications, projects, and experience. Supports English and Chinese, with light and dark themes.

Visit [melmaphother.github.io](https://melmaphother.github.io/).

The site also includes three small tools: Nanobanana Peel, TexPurify, and QRStamp.

Liquid Glass controls use [Liqui Design](https://github.com/leefanv/liqui-design) (`@liqui-design/glass`). The original homepage was based on [Minimal Academic Website](https://github.com/yuhui-zh15/Minimal-Academic-Website).
